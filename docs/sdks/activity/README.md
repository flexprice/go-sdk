# Activity

### Available Operations

* [ListActivity](#listactivity) - List activity

## ListActivity

Use when you need the audit trail of changes to billing entities: who changed what, when, from where. Filter by entity, customer, actor, action or request; pages are newest first.

### Example Usage

<!-- UsageSnippet language="go" operationID="listActivity" method="post" path="/activity" -->
```go

import(
	"context"
	flexprice "github.com/flexprice/go-sdk/v2"
	"github.com/flexprice/go-sdk/v2/models/types"
	"log"
)

func main() {
    ctx := context.Background()

    s := flexprice.New(
        flexprice.WithSecurity("<YOUR_API_KEY_HERE>"),
    )

    res, err := s.Activity.ListActivity(ctx, types.ListActivityRequest{})
    if err != nil {
        log.Fatal(err)
    }
    if res.ListActivityResponse != nil {
        // handle response
    }
}
```
